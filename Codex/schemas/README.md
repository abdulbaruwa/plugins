# Schema provenance

These are unmodified machine-readable Agent Plugins 1.0.0 schemas fetched on 13 October 2026 from the canonical [plugin schema](https://agent-plugins.org/schemas/1.0.0/plugin.schema.json) and [MCP schema](https://agent-plugins.org/schemas/1.0.0/mcp.schema.json). The [specification](https://agent-plugins.org/specification) supplies semantic rules such as literal remote headers and path containment. OpenAI-specific interface metadata is reviewed separately; these schemas do not define that extension.
