# Squarespace for Codex

Community adaptation of upstream 1.0.0 from `third_party/squarespace`. Original authors, assets and MIT license are retained.

Public domain naming/search tools can be used without authentication. Show sponsored labels, first-year and renewal prices, and distinguish an unknown available:null result from unavailable. A checkout link is not a purchase. Commerce is separately client-qualified through CIMD; do not claim native Commerce tools or replace CIMD with DCR.

Register `<repository>/Codex` as the marketplace, then install `squarespace@cursor-plugins-codex`. [Upstream README](references/upstream-readme.md) is reference evidence; its client-specific setup instructions do not override the native qualifications above. Provider authentication and live tools are unverified.
