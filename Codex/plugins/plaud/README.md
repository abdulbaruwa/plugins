# Plaud for Codex

Community adaptation of `third_party/plaud` at upstream version `1.0.1`. Original authors and MIT license are preserved. This is not an official Cursor or OpenAI distribution.

Work with your Plaud recordings: list and search meetings and voice notes, read full transcripts with speaker labels, and pull AI summaries, action items, and key topics into your workflow.

Provider endpoint and portable MCP transport packaged; authentication and live behavior are unverified.

See [compatibility](../../COMPATIBILITY.md) for scope and proof limits and [installation](../../README.md) for marketplace setup.
