# TinyFish for Codex

Community adaptation of `third_party/tinyfish` at upstream version `1.0.1`. Original authors and MIT license are preserved. This is not an official Cursor or OpenAI distribution.

Browse and automate the web with TinyFish: run multi-step web automations, search the web, extract clean page content, and drive remote stealth browser sessions.

Provider endpoint and portable MCP transport packaged; authentication and live behavior are unverified.

See [compatibility](../../COMPATIBILITY.md) for scope and proof limits and [installation](../../README.md) for marketplace setup.
