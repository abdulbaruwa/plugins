# Close for Codex

Community adaptation of upstream 1.0.0 from third_party/close. Original authors, assets and license are retained.

Use the first-party PKCE/DCR connection only after the actual native redirect is accepted; custom-scheme callbacks are rejected. Streamable HTTP only. Consent selects one organization and mcp.read, mcp.write_safe or mcp.write_destructive. Existing-record updates count as destructive, merges/deletes are irreversible, drafts do not send and voice scheduling places real calls. Preview and obtain exact authority for writes, sends, calls and irreversible changes; preserve organization boundaries.

Install close@cursor-plugins-codex from <repository>/Codex. [Upstream README](references/upstream-readme.md) is source evidence; client-specific setup does not override the native qualifications above. Authentication and live behavior remain unverified.
