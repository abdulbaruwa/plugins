# Expensify for Codex

Community adaptation of upstream 1.0.0 from third_party/expensify. Original authors, assets and license are retained.

The source labels availability Grok-only while describing a first-party PKCE/DCR endpoint with mcp:tools. Native registration, redirect and tool access must be qualified before connection; no supported native access is claimed. Tools search expenses and reports visible through the user's approval/admin permissions. No report submission, approval, editing, cards or money movement is supplied.

No connection is enabled; run $setup-expensify after installing this package. [Upstream README](references/upstream-readme.md) is source evidence; client-specific setup does not override the native qualifications above. Authentication and live behavior remain unverified.
