# Engine for Codex

Community adaptation of upstream 1.0.0 from `third_party/engine`. Original authors, assets and MIT license are retained.

Hotel booking tools act for the signed-in member. Bookings charge the saved card or direct bill. Show member, hotel, dates, full price and cancellation terms and get exact approval before booking; preview shortening/cancellation first. Check booking status or offer the provider website after an uncertain result, never blindly retry. Native OAuth and live booking acceptance remain unverified.

Register `<repository>/Codex` as the marketplace, then install `engine@cursor-plugins-codex`. [Upstream README](references/upstream-readme.md) is reference evidence; its client-specific setup instructions do not override the native qualifications above. Provider authentication and live tools are unverified.
