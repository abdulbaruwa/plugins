# Rillet for Codex

Community adaptation of upstream 1.0.0 from third_party/rillet. Original authors, assets and license are retained.

Qualify native PKCE/DCR with read/write and an accepted HTTPS or localhost redirect; custom-scheme callbacks are rejected. The user chooses the organization and tools follow that role. Reports reflect live ledger data. Preview and obtain exact authority for financial writes, payments, contract changes and irreversible deletes; successful OAuth does not authorize those actions.

Install rillet@cursor-plugins-codex from <repository>/Codex. [Upstream README](references/upstream-readme.md) is source evidence; client-specific setup does not override the native qualifications above. Authentication and live behavior remain unverified.
