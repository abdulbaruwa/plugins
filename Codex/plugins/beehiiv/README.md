# beehiiv for Codex

Community adaptation of `third_party/beehiiv` at upstream version `1.0.1`. Original authors and MIT license are preserved. This is not an official Cursor or OpenAI distribution.

Run your beehiiv newsletter from chat: draft and edit posts, organize subscribers with tags, custom fields, and segments, build automations, and review publication, post, and website performance.

Provider endpoint and portable MCP transport packaged; authentication and live behavior are unverified.

See [compatibility](../../COMPATIBILITY.md) for scope and proof limits and [installation](../../README.md) for marketplace setup.
