# Coinbase for Codex

Community adaptation of `third_party/coinbase` at upstream version `1.0.0`. Original authors and MIT license are preserved. This is not an official Cursor or OpenAI distribution.

Check balances, get quotes, and preview or place trades.

Provider endpoint and portable MCP transport packaged; authentication and live behavior are unverified.

See [compatibility](../../COMPATIBILITY.md) for scope and proof limits and [installation](../../README.md) for marketplace setup.
