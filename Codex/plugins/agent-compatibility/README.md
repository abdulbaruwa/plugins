# Agent Compatibility for Codex

Community adaptation of `agent-compatibility` at upstream version `1.0.0`. Original authors and MIT license are preserved. This is not an official Cursor or OpenAI distribution.

CLI-backed repo compatibility scans plus agents that audit startup, validation, and docs against reality.

Codex skill adaptation; Cursor hooks and automatic rules are not installed.

Packaged skills: `$check-agent-compatibility`.

See [compatibility](../../COMPATIBILITY.md) for scope and proof limits and [installation](../../README.md) for marketplace setup.
