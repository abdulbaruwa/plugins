# Why

Read ../../references/codex-runtime.md. Start with the introducing commits and PR discussions and every material later change. Widen to authorized issue, documentation or connected evidence only when the trail is thin. Cite what authors wrote, label inferences, and state what the record cannot answer. Today's implementation is not proof of intent. This workflow does not require investigator fan-out.

The retained native references/epistemics.md and source playbooks are optional evidence aids, preserving earlier research safeguards. Record null results and unavailable sources. Reading does not authorize messages, implementation, or writes. For planned changes, turn supported rationale into preserve/change/avoid/risk constraints.
