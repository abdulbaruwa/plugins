# Show me your work

Read ../../references/codex-runtime.md. Keep one task-owned TSV log using references/decision-log-template.tsv and scripts/log.sh. Record decisions, reasons, evidence pointers, and observed results at meaningful checkpoints. Leave the log uncommitted by default; commit only when the requested deliverable needs a durable audit trail. Keep different runs distinguishable and append corrections rather than rewriting history.

Before handing back, verify each claim against real artifacts and this conversation's available evidence. Use a scoped transcript if supplied; otherwise disclose that transcript comparison was unavailable. An independent read-only reviewer can audit weak evidence, skipped validation, scope creep, and gaps when delegation is available and authorized. Inherit the parent model unless an explicit supported override applies. Label self-review accurately and never claim cross-model review without it. Report attention items with evidence pointers; an empty list is valid.
