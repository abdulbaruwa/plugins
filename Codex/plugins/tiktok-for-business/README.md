# TikTok for Business for Codex

Community adaptation of `third_party/tiktok-for-business` at upstream version `1.0.0`. Original authors and MIT license are preserved. This is not an official Cursor or OpenAI distribution.

Manage TikTok ad campaigns, ad groups, ads, audiences, creatives, and reports.

## Scope and proof

Provider endpoint and portable MCP transport packaged; authentication and live behavior are unverified.

Package validation establishes structure only. Authentication, tool availability, and live provider behavior require separate acceptance checks.

## Installation

Register the standalone marketplace with `codex plugin marketplace add <repository-path>/Codex`, then install this package:

```sh
codex plugin add tiktok-for-business@cursor-plugins-codex
```
