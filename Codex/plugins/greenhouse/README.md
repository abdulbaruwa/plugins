# Greenhouse for Codex

Community adaptation of `third_party/greenhouse` at upstream version `1.0.0`. Original authors and MIT license are preserved. This is not an official Cursor or OpenAI distribution.

Search candidates, jobs, and applications, and review scorecards in Greenhouse Recruiting.

Provider endpoint and portable MCP transport packaged; authentication and live behavior are unverified.
