# Robinhood for Codex

Community adaptation of `third_party/robinhood` at upstream version `1.0.0`. Original authors and MIT license are preserved. This is not an official Cursor or OpenAI distribution.

View portfolios, positions, orders, watchlists, and market data, and trade in a Robinhood Agentic account.

Provider endpoint and portable MCP transport packaged; authentication and live behavior are unverified.

See [compatibility](../../COMPATIBILITY.md) for scope and proof limits and [installation](../../README.md) for marketplace setup.
