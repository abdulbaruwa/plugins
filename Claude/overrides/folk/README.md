# folk for Claude Code

Qualify native PKCE/DCR through api.stytch.folk.app and consent at app.folk.app. Discover folk_get_workspace_structure before using custom groups, fields, pipelines or object names. Roles, plan, connected senders and interaction privacy apply. Campaign creation with target=launch and folk_launch_campaign send irreversible emails: approve exact recipients, steps, sender and send time first. Stops and deletions are irreversible; only draft/in-review campaigns can be deleted and CRM records cannot. Enrichment shares personal data externally and spends credits (one/email, four/phone, refunded for unfound fields); check folk_get_credits and get authority for disclosure and spend before enrichment. Prefer current plural tools over deprecated single-record APIs.

Install from the native marketplace; actual native registration, entitlements and live behavior remain unverified. The source README linked in the banner records upstream evidence, not an executable Cursor/Grok setup flow.
