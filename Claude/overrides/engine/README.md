Show member, hotel, dates, full price and cancellation terms and get exact approval before booking; preview shortening/cancellation first. Install from the native marketplace described above. Use the actual provider sign-in or exposed public read tools; static package validation does not prove native OAuth, entitlements, or live behavior. Do not copy Cursor/Grok account or credential flows.
